# Typhonxy – Downloads

3D-Echtzeitstrategie auf dem Vulkanmond Io. Hier liegen nur die fertigen Spieldateien; der Quellcode ist privat.

**Neueste Version:** [Releases](https://github.com/Typhonxy/typhonxy-releases/releases/latest)

- **Android:** `Typhonxy-x.y.z.apk` herunterladen und öffnen (Installation aus unbekannten Quellen erlauben).
  Die App meldet neue Versionen im Hauptmenü.
- **Windows:** `Typhonxy-Setup-x.y.z.exe` herunterladen und ausführen. Die PC-Version aktualisiert sich danach
  selbst und fragt vor dem Neustart.

Spielstände bleiben bei Updates erhalten.
